# First steps
Upon setting up the server with the plugin, you can now test some awesome features and set some more stuff up. This section of Getting Started will guide you through the basic features, the ones that would actually read out 'Yep! Its working'. We will go through the basic features of this plugin in this section. 
Those are:
- Scoreboard
- Tablist
- Menu
- Economy
Once we've done all that, you're up on yourself to do stuff. You are free to explore anything and configure stuff.

## Scoreboard Basics
So, the scoreboard is basically a box on the left side of your screen which is highly configurable and can show various information. In *SSMP*, this feature module is `enabled` by default. If you want to know how to **toggle the modules on and off**, you might wanna check out [Module Configuration](#modules-configuration).

This scoreboard is **NOT** toggleable by in-game commands by default. That feature is currently not there. But it soon will be. Because this is only the basic section, I won't be going further, more information about **Scoreboard** will be available [here](#features-scoreboard).

## Tablist Basics
This is also very simple. Its the menu that pops up when you hit `tab` on your keyboard. Nothing special, in vanilla multiplayer, its very simple. Just a list, nothing else. But, as you have seen in other big servers (or you haven't), this isn't that simple. It has information about the **world**, the **online players**, and mostly the **server location**. There can be more, like the **server name printed in big letters**. In **SSMP**, you can find the similar tablist experience. 

Just hit `tab`, and get a glance at it! Like other modules, this module is also highly configurable. You can change what you see here too, or just disable it. To **toggle** this module, check out [Module Configuration](#modules-configuration). More information about **Tablist** will be available [here](#features-tablist).

## Main Menu
This is the menu which opens when you either do the `/ssmp` command or click the **compass item** in the *9th* slot of your hotbar. Currently, it contains the buttons for most modules. If we zoom out, this menu can be accessed by the *menu-item*, which can also be `enabled` or `disabled` through the config file, as it is also a module.

The menuitem can also be configured. For more information on Main Menu can be found [here](#features-mainmenu). This is the menu designed for clients, in this case, you.

## Economy Basics
So this is the final section of your first steps in the plugin. To finish off, I'll just introduce you to the first ever feature on this plugin. This is the **SSMP-ECONOMY**. You can access various economy commands through `/economy <args>`. The args can be `pay`, `give`, `set`, `remove` etc. Your balance will be visible on the **Scoreboard** too. As always, this module is also toggleable, but it will kind of break things if you do toggle it off (Just procastinating, not sure).

So that concludes your first steps. Now its up to you on exploring different features.
