# Welcome
Breif on what Siddy's Simple Plugin's objective is.

Welcome to this amazing documentation. This documentation focuses on setting up the user experience to install or modify Siddy's Simple Plugin is. Basically, Siddy's Simple Plugin is a **Spigot / Paper / Bukkit / Purpur** plugin that focuses on one major thing - All-In-One. Now imagine a scenario, You're tired playing the same old survival, and want some twist. Your friends keep on bragging about the lack of features in your custom SMP, but you don't wanna lose the position of being the Owner. You have zero, or very less experience in setting up servers, and once you get your hands on a *Spigot Server Jar*, You're confused like a goose!

Siddy's Simple Plugin's main idea is simplicity. I designed this to be completely begginer friendly. You don't need a degree in computer science to understand what's going on. There is soon going to be a **Debug** version of this plugin, so stay tuned for it.
